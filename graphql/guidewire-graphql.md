# Guidewire GraphQL API

Guidewire is a cloud platform for property and casualty insurance covering policy administration, billing, and claims management. The API covers policies, quotes, billing accounts, claims, payments, and integration with insurance core systems.

**Endpoint:** No native GraphQL endpoint — conceptual schema derived from Guidewire REST API
**Documentation:** https://docs.guidewire.com/

- Reference: https://docs.guidewire.com/cloud/pc/en-US/rest_api_framework/rest_api_framework-10.0.0/api_reference/
- Schema: https://github.com/api-evangelist/guidewire
